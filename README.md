# Car App

Учебный проект по сортировке объектов класса Car с использованием паттерна Strategy.

## Команда
- Участник 1 — модель, Builder, работа с файлами
- Участник 2 — стратегии сортировки, ДЗ1
- Участник 3 — меню, интеграция, тесты
- Участник 4 — Stream API, многопоточка, кастомные коллекции

## Как запустить
1. Открыть проект в IntelliJ IDEA.
2. Запустить `Main.java`.
3. Выбрать пункты меню.

## Функционал
- Заполнение массива: вручную, из TXT, из JSON, рандомно через Stream.
- Сортировки по 3 полям + сортировка по всем полям.
- ДЗ1: сортировка чётных цен.
- ДЗ2: сохранение с добавлением в файл.
- ДЗ3/3*: Stream API + кастомные коллекции.
- ДЗ4: многопоточный подсчёт вхождений.
- Тесты: модульные + интеграционные.
